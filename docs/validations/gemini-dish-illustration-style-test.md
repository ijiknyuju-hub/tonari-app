# Gemini料理イラスト・スタイル固定テスト

Status: prompt baseline and harness ready / waiting for API key (2026-07-18)

## 目的

実写撮影なしで全料理を揃えるため、まず代表20皿で「となりごはんの料理だと分かる」再現可能な生成条件を固める。モデルの追加学習は、固定プロンプトと参照画像で再現できない失敗が30件以上集まってから検討する。

## 現時点のモデル候補

公式ドキュメント上、量産の第一候補はGemini 3.1 Flash Image、低コスト試行はGemini 3.1 Flash Lite Image、最終品質比較はGemini 3 Pro Image。複数参照画像と一貫性はFlash Imageが主用途に合う。全生成画像にはSynthIDが付く。

2026-07-18時点の公式価格例では、1K画像はFlash Imageが約$0.067/枚、Flash Lite Imageが約$0.0336/枚。価格とpreview状態は実行前に再確認する。

一次資料:

- https://ai.google.dev/gemini-api/docs/image-generation
- https://ai.google.dev/gemini-api/docs/pricing
- https://ai.google.dev/gemini-api/docs/changelog

## 代表20皿

- ごはん: カレー、チャーハン、親子丼、オムライス
- 麺: ナポリタン、ペペロンチーノ、焼きそば、うどん
- 主菜・肉: 唐揚げ、生姜焼き、ハンバーグ、肉じゃが
- 主菜・魚: 鮭の塩焼き、さばの味噌煮
- 卵・豆腐: 麻婆豆腐、だし巻き卵
- 副菜: 冷奴、ほうれん草のおひたし、もやしのナムル
- 汁物: 豚汁

## 固定する生成仕様

- 4:3、1024px、料理単体、真上から少し斜めの同一視点
- 家庭の食卓、自然な量、過度な湯気・照り・広告的演出なし
- 背景、器、影、余白、彩度、線/質感を参照画像で固定
- 文字、人物、手、箸、パッケージ、ロゴを出さない
- 料理名ごとに必須食材、禁止食材、器種、盛り付けを構造化して渡す
- 同じseed相当の入力条件と生成パラメータを記録する

## 最初の少数比較

60枚を先に量産せず、性質の異なる3皿を1候補ずつ生成してプロンプトの大崩れを確認する。

- ガパオライス: 過去検証で残った「ひき肉を粒ごとに囲む／逆にソースへ溶かす」問題
- 鶏の唐揚げ: 小カード同定と過剰な照り・衣の均一化
- ほうれん草のおひたし: 副菜の量感と緑の塊化、別料理化

固定入力は`gemini-dish-prompt-cases.json`、実行スクリプトは`scripts/generate-gemini-dish-style-test.mjs`。APIキーは`.env.local`またはプロセス環境変数からだけ読み、リポジトリへ保存しない。

```bash
npm run validate:gemini-illustrations
npm run validate:gemini-illustrations -- --dish=gapao --candidates=3
```

出力先は`design/gemini-dish-style-test/`。各画像と完全なプロンプト、モデル、生成時間、利用量を`manifest.json`へ記録する。

## 評価方法

各皿を3候補生成し、2人が0〜2点で採点する。

| 評価軸 | 0 | 1 | 2 |
|---|---|---|---|
| 料理同定 | 別料理 | 迷う | 一目で分かる |
| 食材正確性 | 明確な誤り | 軽微な不足 | 正確 |
| 家庭料理感 | 広告/高級店 | やや演出過多 | 日常的 |
| スタイル一貫性 | 別シリーズ | 一部ずれ | 統一 |
| 小カード判別 | 判別不能 | 名前併用で可 | 絵だけで可 |
| UI適合 | 切れ/余白不良 | 調整可能 | そのまま使用可 |

合格は12点中10点以上、かつ料理同定・食材正確性が各2点。各皿に最低1候補合格、全体合格率80%以上を量産開始条件とする。

## 量産前に残すもの

- 採用参照画像3〜5枚
- 基本プロンプト、料理別差分、禁止プロンプト
- モデルID、日付、価格、解像度、生成時間
- 全候補と採点結果
- 失敗パターン辞書
- 再生成回数と1採用品あたりの実費

## 撤退線

- 3回生成しても料理同定が安定しない料理が20%以上
- 器や視点を固定すると食材誤りが増える
- 1採用品あたり平均10回以上の生成が必要

撤退線を超えた料理だけ、現行の抽象`DishArt`または権利確認済み素材へフォールバックする。
