# A-0 生語彙抽出の結果 — 2026-07-17

spec-032 Phase A-0。282皿をSonnet 6本で分割抽出（統制なし）。
生データ: `data/vocab/a0-raw-282.json`（282件、欠落・余剰・重複ゼロ）

## 規模：見積もりは3項目とも外れた

| | 事前見積もり | 実測（生） | 判定 |
|---|---|---|---|
| 調味料 | 70語前後 | **120語** | 低かった（1.7倍） |
| 食材 | 120〜180語 | **268語** | 低かった |
| 調理法 | 12〜15語・閉じた集合 | **70語** | **大きく外した** |

調味料の120は畳む前の生語彙なので、別名を寄せれば70前後に落ちる見込み（＝見積もりは
post-merge の数としては妥当）。一方**調理法の「閉じた集合・ほぼ完成」は完全な誤り**だった。

調味料120語のうち**53語が1回しか出現しない**（hapax）。これがIDFで効く「珍しい＝皿の正体」の裾。

## 発見1: 表記ゆれが実在した（別名テーブルが前提条件である証拠）

| 衝突 | 出現数 |
|---|---|
| だし / 出汁 | 40 / 8 — **同語の表記違い** |
| にんにく / おろしにんにく | 27 / 11 — 形状違い |
| しょうが / 生姜 | 10 / 4 — 表記違い |
| 鶏がらスープ / 鶏がらスープの素 | 11 / 10 — 実質同一 |
| 塩こしょう / 塩 + こしょう | 38 / 42 + 8 — **複合語。分割すべき** |

食材側はさらに激しい。同一の豚バラが5通りに割れている:
`豚バラ肉(12) / 豚バラ肉(薄切り)(4) / 豚バラ薄切り肉(2) / 豚バラ肉(ブロック)(1) / 豚バラ肉（厚切りブロック）(1)`
牛の薄切りも3通り: `牛薄切り肉(2) / 牛肉薄切り(2) / 牛肉(薄切り)(1)`

**これがv1のノイズと同じ経路で効く**。畳まなければ、同じ豚バラの皿同士が一致しない。

## 発見2: 調理法70語の正体は3種類の混在

1. **下ごしらえ動詞（調理法ではない — カテゴリ誤り）**: 切る / 千切りにする / ささがきにする /
   叩く / 潰す / 裏ごしする / 成形する / こねる / 丸める / 血抜きする / 練る / 衣をつける / 寝かせる
   → **語彙から落とす**。皿の近さを決めない。
2. **括弧付きの重複**: 焼く（表面を焼く）/ 焼く（オーブンで焼く）/ 焼く（表面を炙る）/
   煮る（煮込む）/ 蒸す（酒蒸しにする）/ 蒸し焼きにする（ホイルで包んで焼く）
   → 親の語に畳む。
3. **本物の穴（v2語彙に無く、実際に必要）**: 炊く(5) / 蒸し焼きにする(2) / 揚げ焼きする / 素揚げする /
   電子レンジで加熱する(2) / 湯煎する / 低温でじっくり火を通す / 卵でとじる(3) / 絡める(6) / とろみをつける(5)

1と2を除くと**実質20語前後**。「12〜15」は近かったが、**閉じているという前提が誤り**だった。

## 発見3: 非加熱の皿にmethodが無い

冷奴 / 納豆 / ホタテのカルパッチョ / 冷やしトマト。3本のエージェントが独立に
「盛り付ける」「混ぜる」「冷やす」を発明した。**加熱しない皿をどう扱うかがスキーマ上未定義**。

## 発見4: 役割タグの穴 — 生卵

独立に3チャンクから上がった。すき焼きのつけ卵 / 釜玉うどんの卵 / 親子丼のとじ卵 は
coat でも bind でも thicken でもない。エージェントは sub や main に逃がした。
餃子の皮・春巻きの皮・パイシートも `base`（炭水化物）の例示に合わず、逃がされている。

役割の分布: sub 513 / main 315 / coat 88 / base 77 / thicken 23 / **bind 20**。
bind は20回しか使われていない。

## 発見5: 1皿の中で同じ食材が2役を持つ（3件が独立に再現）

酢豚・えびチリ / 肉団子 / 鶏の黒酢あん — **片栗粉が衣（coat）とあんのとろみ（thicken）で2回出る**。
スキーマが同一皿内の同名食材の重複を許すかが未定義。

## 発見6: 米 と ごはん は別物

リゾット・ピラフ・パエリア・ジャンバラヤは生米から作る。豚丼・そぼろ丼は炊いたごはんに乗せる。
naive に畳むと消える区別。

## カタログ側の発見

**「手羽元の照り焼き・さっぱり煮」は1つの名前に2皿が入っている**（照り焼き ≠ 酢の煮物、
同じ調理で両方は作らない）。分割するか片方に寄せるかの裁定が要る。
