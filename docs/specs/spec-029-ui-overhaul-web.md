# Spec 029: UI Overhaul (Web v2.9)

Approved: 2026-07-03（design research → directives。ADR-008）
Research sources: Tubik food-app card studies, Duolingo streak/progress system, Kurashiru/DELISH KITCHEN/NYT Cooking benchmarks, text-first food UI patterns. Raw directives in main-repo session 2026-07-03.

## Design Goal

「AIが作った汎用カードUI」から「意図を持ってデザインされたプロダクト」へ。機能は変えない。見た目の焦点・余白・タイポグラフィ・色の使い方だけを作り替える。

判断基準は価値の核5層: 感情の核=「探さなくても出てくる」「これなら作れそう」。画面の焦点は常に1つ（今日の一品、次のマイルストーン）で、それ以外は視覚的に後退させる。

## Core Directives (research-derived, binding)

### 1. 色の制約 — アクセントの集中投下
- **アクセント（orange系）の使用箇所を3つに限定**: (a) 主CTA（作った/保存ボタン） (b) 島マップの「作った」タイル (c) フィーチャーカードの上辺ボーダー1本
- 現在のように複数チップ・バッジ・アイコンにorangeが散っている状態を解消する。チップ類はニュートラル（枠線+テキスト）に落とす
- アクセントは現行の明るいorangeから焦がしオレンジ #C8531C 系へ調整（温かさ+洗練。生のオレンジは汎用感の主因）
- 背景はwarm cream維持。テキストはcharcoal（コントラスト7:1以上）

### 2. タイポグラフィ — 料理名を主役に
- 料理名: 22px bold、letter-spacing −0.02em（画面の主役はテキスト。写真がない分ここで勝負する）
- メタ情報（時間・難度・差分数）: 13px、60%不透明度
- セクション見出し: 16-18px bold、上24px/下12pxマージン
- 本文（差分説明2行）: 15px、line-height 1.7

### 3. スペーシング — 縦に贅沢に
- 4pxグリッド。カード間は20px以上（現12px相当は詰まりすぎ）
- 縦方向の余白は横方向の2倍を基準にする（スクロール前提の視線誘導）
- カード内: 横16px、上12px、下16px
- 影: blur 2px / offset 2px / black 8%（重い影は禁止）

### 4. カード解剖 — 1カード1アクセント
- ヒーロー要素は1つだけ: 絵文字（32-48px、料理と1:1対応）or 色ブロック or ボーダー。全部盛りは禁止
- テキストブロックは絵文字と重ねず下に分離
- 属性チップの多色展開禁止（難度は1個のニュートラルバッジのみ）
- カードグリッドは左揃え（センタリング禁止）

### 5. 島マップ — 状態の視覚言語を統一
- 作った: フルカラー+影（2-4px offset）
- 作れる（となり）: 60%彩度、影なし
- 未踏: 40%不透明度、影なし
- 状態変化（新しい島の解放）は0.4s scale+fadeアニメーション

### 6. 達成の演出 — 静かな更新をやめる
- マイルストーン到達: フルスクリーン祝福モーダル（絵文字+「{N}品達成！」+ 次の目標1行 + ボタン1つ）。1.2s自動表示→タップで閉じる
- レパートリータブの達成ヘッダー: 品数28px bold左揃え+進捗バー（「あと{X}品で{milestone}品」）
- 記録完了ステップの祝福は既存を本ディレクティブのスタイルに合わせる

### 7. 消すもの（アンチパターン）
- 等サイズカードの均等グリッド羅列（重要度に応じてフィーチャーカードを大きく）
- アイコンだけのナビ（必ずアイコン+ラベル）
- 画面あたり3色以上のアクセント
- プレースホルダー的な汎用カード

## Screen-by-screen application

- **ホーム**: 今日の一品カードを唯一の大型要素に（上辺アクセントボーダー+絵文字48px+料理名22px）。その他カードは小さく静かに。ナッジバーはニュートラル背景+テキストリンク風ボタン
- **レパートリー**: 達成ヘッダー（§6）→ セグメント切替（ニュートラル）→ マップ/リスト。リスト行は料理名主役+状態バッジ1個
- **食材**: チップはニュートラル枠線、選択時のみ焦がしオレンジ塗り。結果カードは§4準拠
- **料理詳細**: 料理名を画面最上部の主役に。材料/手順はリスト行の行間を広く。編集モードは鉛筆アイコン+「自分流」バッジ（アクセント使用OK — 所有感の演出はCTA級）
- **オンボーディング**: 皿グリッドは絵文字40px+名前、選択時に焦がしオレンジ枠。コピーは記憶の核「レシピを探すんじゃなくて、レパートリーを育てる」を1画面目に

## Token updates (mocks/design-tokens.md への追記案 — 実装後に正本へ反映)

- accent: #C8531C（旧orangeを置換）/ accent-soft: #F5E3D7
- text: #2B2725 / text-secondary: rgba(43,39,37,0.6)
- shadow-card: 0 2px 2px rgba(0,0,0,0.08)
- spacing: 4px base、card-gap 20px

## Done When

- [ ] 全画面でアクセント使用箇所が3種の枠内に収まっている
- [ ] 料理名22px/メタ13pxのスケールが全カード・全リストに適用
- [ ] カード間20px+、縦余白優位のリズムが全画面で成立
- [ ] 島マップ3状態の視覚言語が統一
- [ ] マイルストーン祝福モーダルが発火する
- [ ] `npm run lint` / `npm run build` パス
- [ ] 機能のリグレッションなし（このspecは見た目のみ）
