# 週セット・買い物リストの置き場所 = ホーム起点フロー + フェーズ別入口（U21一部決着）

- Context: 週セット(5a)・買い物リスト(5b)をどの画面に置くか（spec-030 U21「置き場所とタブ構成への影響」）。キャンバスの5a/5bにはボトムナビが無い。3タブ維持はspec明記、探すは検索純化済み、料理帳は所有の場で性格違い。
- Decision: 4タブ化・探す/料理帳同居は不採用。`/weekset` `/shopping` はボトムナビなしの全画面フロー（戻るはヘッダー）。入口はホーム上の状態機械: 未編成=1行バナー「今週のセットを組む」→5a / 編成済み・買い物前=チップ「買い物リスト のこりN品」→5b / 買い物完了=チップ消滅・ホーム二状態「セット有り」に切替（文脈行タップで5a閲覧）。5aのCTA→5bの一本道。
- Rationale: 店頭速度（起動→1タップ）、非利用者への無要求（未編成バナー1行のみ）、プラス意識のピーク（買い物計画時）に入口が現れ儀式後に消える — 常設タブの錆び回避。キャンバスのナビ無し設計とも一致。
- Note: ホーム1aに入口要素は未描画のため、挨拶行と難易度タブの間に既存トークンのみで最小実装し、後日claude.ai/designへ逆輸入して整える（オーナーGO 2026-07-15）。
