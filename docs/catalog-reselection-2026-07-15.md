# 判定が要る論点（3つ）

1. **箱の定義そのもの（2件が同じ穴を指している）**:
   - 「主菜（魚）」箱に**魚以外の魚介がどう入るか**が未定義。既存のエビフライ・エビチリはエビ（甲殻類）、追加提案のあさりの酒蒸しは貝。今回は魚箱に置いたまま出したが、厳密には魚ではない。箱を「魚介」に読み替えるのか、エビ・貝を別扱いにするのかは決めていない
   - **冷奴**は決定木Step3「おかずの主役か」に照らすと主菜ではなく副菜・おとも寄り。汎用ルール（豆腐が骨格なら卵・豆腐箱）と主役判定が衝突する初の実例
2. **四川風麻婆豆腐**: ベースの麻婆豆腐と実質重複か、本場スタイルの別皿か
3. **麺箱をどこまで削るか**: パスタ18件はSonnet側が「個別に見ればどれも実在のメジャー料理」として全部残す判断をした。ただしごはん・麺83件は主菜77件より多いままで、カタログの重心が炭水化物に寄る。ここは「実在するか」ではなく「カタログの重心をどう置くか」の設計判断なので、オーナー裁定が要る

# 次の一手（この判定の後）

主菜のバルク収集パス。目標150-200に対して77件では、週セットのドラフトが同じ皿を毎週出すことになります。魚の穴が塞がった状態から、肉・卵豆腐のメジャー料理を定番ランキング起点でフラットに拾う（07-08方針の本流）。
